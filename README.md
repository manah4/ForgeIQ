# ForgeIQ

AI-powered multimodal engineering review assistant built with Google Gemini 3.6 Flash.

## Overview

ForgeIQ analyzes engineering drawings and technical images to generate AI-assisted design reviews for biomedical and mechanical engineering applications.

## Features

- Multimodal image analysis
- Biomedical engineering review
- Material recommendations
- Manufacturability analysis
- Risk and failure assessment
- Engineering report generation

## Built With

- Google AI Studio
- Gemini 3.6 Flash
- Gemini API
